# KeyDrive · 密钥共享空间 ☁️

一个**免登录**的资料共享网站：进网站 → 创建密钥或输入密钥 → 凭密钥上传文件、保存文字资料。把密钥发给别人，对方输入后就能看到这个空间里的所有内容。类似 OneDrive，但"密钥"就是一切，没有账号体系。

## 快速开始

只需要安装 [Node.js](https://nodejs.org)（16 或更高版本），无需 `npm install`：

```bash
node server.js          # 或者：npm start
```

然后浏览器打开 <http://localhost:3000>。

### 常用启动参数（环境变量）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `3000` | 服务端口 |
| `HOST` | `0.0.0.0` | 监听地址（`127.0.0.1` 则仅本机可访问） |
| `MAX_FILE_MB` | `200` | 单个上传文件的大小上限（MB） |

例如换端口并允许 1GB 大文件：

```bash
PORT=8080 MAX_FILE_MB=1024 node server.js
```

## 使用方法

1. **创建密钥**：首页点击「创建新密钥」，得到一串形如 `K7M2-9QX4-BT8F` 的密钥（只此一份，请立即复制保存）。
2. **进入空间**：输入密钥进入，可以：
   - ✏️ 保存文字资料（说明、备忘、链接等）
   - 📤 上传文件（支持多选和拖拽，图片自动生成缩略图）
   - ⬇️ 下载 / 🗑️ 删除文件
3. **共享**：把密钥（或页面上复制的 `http://你的地址/#密钥` 直达链接）发给他人，对方在首页输入密钥即可看到全部内容，也可以继续上传。
4. **再次进入**：本机用过的密钥会显示在首页「最近使用」里；密钥丢失则无法找回。

## 如何让别人访问（远程使用）

- **同一 Wi-Fi / 局域网**：直接访问 `http://<你的IP>:3000`（服务启动时会打印提示）。
- **公网**：把服务部署到云服务器，或在家庭宽带上做端口转发 / 使用 frp、Tailscale、Cloudflare Tunnel 等内网穿透工具。

### 部署方式

GitHub 只托管代码（本项目是 Node 服务端，GitHub Pages 无法运行）。三种常见部署方式：

**① Docker（任意服务器 / 群晖 / 软路由）**

```bash
docker build -t keydrive .
docker run -d --name keydrive -p 3000:3000 -v keydrive-data:/app/data keydrive
```

**② Render（免费，一键拉取本仓库）**

1. 登录 [render.com](https://render.com) → New → Web Service → 连接本 GitHub 仓库
2. Build Command 留空，Start Command 填 `node server.js`
3. 创建后在 Settings → Disks 挂一块持久盘，挂载路径填 `/app/data`（否则重新部署后上传的文件会丢失）

**③ Railway / 其它支持 Node 的平台**：直接用仓库根目录的 `npm start` 启动，记得给 `/app/data`（即项目内 `data/`）配持久化存储。

> 注意：密钥与文件都保存在主机的 `data/` 目录里，请定期备份；平台磁盘是临时盘的话务必挂持久盘。


## 数据与安全

- 所有数据保存在 `data/vaults/` 目录下，目录名是密钥的 SHA-256 哈希——**服务器不保存明文密钥**，删除该目录即可彻底清除对应空间。
- 密钥是唯一凭证：任何拿到密钥的人都可以**查看、上传、修改、删除**该空间的内容（类似共享编辑的在线文件夹），请只发给你信任的人。
- 空间页提供「删除整个空间」按钮（需两次确认）。
- 本项目面向个人/小团队内部共享场景，未内置 HTTPS；如需公网使用，建议套一层反向代理（Nginx / Caddy）并启用 HTTPS。

## 技术说明

- 后端：Node.js 原生 `http` 模块，**零依赖**；上传采用流式写入，不占用大量内存。
- 前端：原生 HTML/CSS/JS 单页应用，无任何框架。
- 文件结构：

```
server.js          # 全部后端逻辑（API + 静态文件服务）
public/index.html  # 页面结构
public/style.css   # 样式
public/app.js      # 前端逻辑
data/vaults/       # 运行后自动生成的数据目录
```
